# Ask Help

Help has a search bar at the top. It finds a section of these docs, and it can answer a question.

## Search the docs

1. Type a word in the search bar.
2. Select a result to open that section.

Select **Clear** to go back to the page.

## Ask a question

Turbo shows **Ask Help** as the first result if you can ask questions.

1. Type your question in the search bar.
2. Press Enter.
3. Read the answer and open its sources.

Type the next question in the box under the answer.

## Go between the docs and your answers

Help shows two tabs after your first question.

- Select **Docs** to read a page.
- Select **Ask** to return to your answers.
- Select **End chat** to remove your answers and the tabs.

## Check the answer

An AI model writes the answer from these docs and from the rules in Turbo. The answer can be wrong, so open the sources under it. Help can't see your time sheets, expenses or purchase orders.

## Rate an answer

Select the thumbs up or the thumbs down under an answer. After a thumbs down, you can say what was wrong. Ratings show us which answers to improve.

## What Turbo records

Turbo records each question, its answer and your rating. Staff who improve Help can read them. Don't type a password or private details in a question.
