# Duplicate clients, contacts and vendors

When two clients, contacts or vendors are the same, staff with absorb access absorb them into one record. Anyone can propose an absorb for them to review.

## Propose an absorb

1. Select the absorb icon beside the record to keep, on **Clients**, **Vendors** or a client's contacts.
2. In **Select Record**, select each duplicate.
3. Enter the **Reason**.
4. Select **Propose**.

Your proposal shows on **Absorb Proposals** under **Business**. To withdraw it, select **Withdraw** beside it.

## Review a proposal

Only staff with absorb access can do this.

1. Select **Absorb Proposals** under **Business**.
2. Select **Review** beside a proposal.
3. To keep a different record, select **Keep this record instead** beside it.
4. Select **Absorb**.
5. On the **Absorb Actions** page, select **Commit**.

## Decline a proposal

1. Select **Decline** beside the proposal.
2. Enter why.
3. Select **Decline**.

## What the person who proposed sees

Turbo tells them when you commit the absorb or decline the proposal. If another absorb removes one of its records, Turbo closes the proposal and tells them. The **Decided** tab shows each outcome.

## Delete a withdrawn proposal

Only the person who proposed it can do this.

1. On **Absorb Proposals**, select the **Decided** tab.
2. Select **Delete** beside your withdrawn proposal.
3. Select **Delete** to confirm. You can't undo this.
