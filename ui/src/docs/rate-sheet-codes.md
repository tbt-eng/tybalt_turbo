# Rate sheet codes

Each rate sheet has a code. People read, print and search for a sheet by its code. A sheet can also have a name.

## The code of a rate sheet

Turbo gives each rate sheet a code when you save it, such as 2026-11-00004. The code starts with the year and month of the first save. Every revision has the same code and its own revision number, such as **2026-11-00004 (rev. 2)**. Printed rate sheets and Project Authorizations show the code. You can't change a code.

## The name of a rate sheet

The name is optional. It describes the sheet, such as a client or a contract. Two sheets can't have the same name, in any letter case. Every revision has the name of its sheet.

## Rename a rate sheet

Only admins and staff with revision access can do this. Every revision gets the new name. The code doesn't change, and jobs keep the sheet.

1. Open the sheet and select **Rename**.
2. Enter the **Name**, or clear it, and select **Rename**.

The sheet shows its old names after **Formerly**.
