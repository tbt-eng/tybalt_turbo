# Rate sheet codes

Each rate sheet has a code. People read, print and search for a sheet by its code.

## The code of a rate sheet

Turbo gives each rate sheet a code when you save it, such as 2026-11-00004. The code starts with the year and month of the first save. Every revision has the same code and its own revision number, such as **2026-11-00004 (rev. 2)**. Printed rate sheets and Project Authorizations show the code. You can't change a code.
