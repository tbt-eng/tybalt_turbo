# Rate sheet periods

A project can use different rate sheets over time. Each period uses one rate sheet from its start date. Turbo prices each time entry with the rate sheet for the entry's date. The project's **Rate sheets** section lists its periods.

## Set the first rate sheet

Procurement does this. All of the project's time, past and future, then uses this rate sheet.

1. Open the project.
2. Select **Set rate sheet**.
3. Select the rate sheet.
4. Select **Save**.

A project with no rate sheet uses default rates for all of its time.

## Start a new rate sheet

Only some staff can do this. They see **New period**.

1. Open the project.
2. Select **New period**.
3. Select the rate sheet.
4. Enter the **Starts on** date. It can't be in the future, or before the rate sheet took effect.
5. Enter the **Reason**.
6. Select **Save**.

Turbo prices time from that date with the new rate sheet. Past values can change.

## Move projects to a revision

Only admins can do this. Active projects on older revisions get a new period.

1. Open the latest revision of the rate sheet and select **Move projects**.
2. Enter the **Starts on** date and the **Reason**.
3. Check the projects that move and those that Turbo skips.
4. Select **Move projects**.

Time from that date uses the new rates. Earlier time keeps its price.

## Change a period

1. Select **Change** on the period.
2. Change the **Rate sheet** or the **Starts on** date.
3. Enter the **Reason**.
4. Select **Save**.

Turbo prices that period's time again. Past values can change.

## Delete a period

1. Select **Delete** on the period.
2. Select **Delete** again to confirm.

The period before it then prices that time. You can't delete the first period.
