# Admin profiles

An admin profile holds a person's payroll ID, default branch and time off balances. It is not the [profile](/docs/profile) that each person changes for themselves. Admins, HR and staff who manage time off can open a person's admin profile. Other staff can't open one.

## Find an admin profile

1. Select **Admin Profiles** under **Business**.
2. Search for the person.
3. Select the name to open the profile.

Select **Inactive** to list people who are not active.

## Change an admin profile

1. Find the person in **Admin Profiles**.
2. Select **Edit**.
3. Change the values.
4. Select **Save**.

You can change your own admin profile in the same way.

## Who can change what

- An admin changes every value, and the person's claims and PO approval limits.
- HR changes most values, but not claims or limits.
- Staff who manage time off change **Opening Date**, **Opening OP**, **Opening OV** and **Payroll ID**.
