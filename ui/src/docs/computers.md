# Computers

Each Windows computer reports to Turbo when a person signs in to it. Turbo lists the computers and the last user of each. Staff who manage computers and admins can see the list.

## Find a computer

1. Select **Computers** under **Business**.
2. Search for the computer name, serial, model or person.
3. Select the computer name to open the computer.

Each row shows the last sign-in, the last user and the assignment.

## Assign a computer

Assign gives a computer to its last user.

1. Find the computer in **Computers**.
2. Select **Assign**.

**Assign** shows when nobody has the computer, or when someone other than the last user has it. Turbo can't assign a computer if the last user isn't a Turbo user.

## Computer details

The page of a computer shows its hardware, Windows version, network adapters and assignment. **Logins** lists its sign-ins of the last 30 days, with the Turbo user that each one matched.

Select **Assign to** and the name to assign the computer to its last user.

## Retire a computer

Retire a computer that the company no longer uses.

1. Open the computer.
2. Select **More actions**.
3. Select **Retire**.
4. Select **Retire** again to confirm.

## Retired computers

1. Select **Computers** under **Business**.
2. Select **Retired**.
3. Select **Un-retire** to put a computer back in **Computers**.

## Logins

A login is one sign-in to a computer.

1. Select **Computers** under **Business**.
2. Select **Logins**.
3. Search for a computer name, serial or person.

The newest login is first. Each row shows the computer, the name that the computer reported and the Turbo user that matched it. Turbo keeps each login for 30 days.

## Raw logins

A raw login is a report that Turbo rejected because it is not complete or not valid. It changes no computer.

1. Select **Computers** under **Business**.
2. Select **Raw Logins**.
3. Select **Report** to see what the computer sent.

The next good report from the same computer name deletes its raw logins. Turbo deletes the others after 30 days.

## Delete a raw login

1. Find the report in **Raw Logins**.
2. Select **Delete**.
3. Select **Delete** again to confirm.
