# Start here

Turbo shows only the features that you have access to, so your menu can differ from other people's menus. Select **Help** at the top of the menu to open these docs. Many screens also have a **Help** button that shows the steps for that screen. To find a topic or ask a question, use the search bar at the top of Help. A red dot on **Help** means that [What's new](/docs/whats-new) has a new week. Open that page to clear the dot.

## Choose your manager

Select your email address under **Account**. Select your **Manager** and save. This person approves your time sheets and expenses. See [Profile](/docs/profile).

## Enter your time

Enter your [time](/docs/time) each day. When the week is complete, select **Submit** on **Entries**. Your manager approves it.

## Buy something for the company

Get approval first. Create a [purchase order](/docs/purchase-orders). Make the purchase only after the PO is Active.

## Record what you spent

Create an [expense](/docs/expenses) and submit it. Your manager approves it.

## Start a proposal

Only procurement can create a [proposal](/docs/proposals) in Turbo. Ask procurement to create it.

## Start a new project

Create a [project request](/docs/project-requests). An approver checks it, then procurement creates the job.

## Invoice a client

Invoicing staff record each [client invoice](/docs/client-invoices) in Turbo. They then link the billed-back costs to it.

## Check a word

The [glossary](/docs/glossary) defines the words that Turbo uses.
