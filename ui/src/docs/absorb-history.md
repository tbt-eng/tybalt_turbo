# Absorb history

Turbo keeps each committed absorb for 90 days. Use the history to find who absorbed a record and what changed. Only staff with absorb access can see it.

## Find an absorb

1. Select **Absorb Actions** in the menu.
2. Select the **History** tab.
3. Search for the kept record, an absorbed record or a person.

Each row shows the kept record, the absorbed records, and who absorbed and who committed.

## See what changed

Select **Details** on a row. Turbo shows the absorbed records as they were and each reference that moved to the kept record.
