# What's new

This page is for people who already know Turbo and want a high-level view of recent changes. For details, or to learn how to use Turbo, see the [other Help pages](/docs/start-here).

## November 15 to 21, 2026 (to f482f482)

### Project requests

- If no active rate sheet has the client's rates, you can propose new rates in a project request. Start from an active sheet and change the rates. The approver approves them with the request. (v0.3.201, v0.3.203, v0.3.204, v0.3.208)
- Select **Find by rates** in a project request to list the active sheets that have the rates you know. (v0.3.215, v0.3.216)
- The plus button beside **Jobs** now starts every new project. It offers **Create a proposal**, **Find the proposal** and **Request a project without a proposal**. (v0.3.206, v0.3.218)
- You can print a Project Authorization for signature when its proposed rates have a rate for every role. The printout keeps the agreement with the signatures. (v0.3.207, v0.3.209)
- Procurement's **Duplicate-work review** lists exact matches and the client's open projects with an award or time in the last year. (v0.3.220)

### Rate sheets

- Each rate sheet now has a code, such as 2026-11-00004. Lists, pickers and printed pages show it. The name is optional. (v0.3.205)
- Admins and staff with revision access can **Rename** a rate sheet, or clear its name. (v0.3.205)
- You can search for a rate sheet by job number or client. The clipboard icon beside a code copies it. A sheet's page lists its **Jobs and clients**. (v0.3.210, v0.3.211, v0.3.212, v0.3.214)
- **Client details** lists the rate sheets of the client's jobs. (v0.3.213, v0.3.214)
- Admins can **Delete** an inactive rate sheet that no job or project request uses or has used. (v0.3.219, v0.3.220)
- **Rate Sheets** is now in the menu for admins and for staff who can create or approve project requests. (v0.3.220)

### Computers

- Staff who manage computers, and admins, can see each Windows computer and its last user in **Computers**. They can assign, retire and un-retire a computer, and see **Logins** and **Raw Logins**. (v0.3.222, v0.3.223, v0.3.224)

### Menu

- The eye button next to your email address now shows every link in the menu. You still can't use features that you don't have access to. (v0.3.206)

## November 8 to 14, 2026 (to d558cf5c)

### Help

- You can now ask Help a question in plain words. It answers from Turbo's docs and code, and it knows your own limits and settings. Type the question in the Help search bar and select **Ask Help**, or use the box on the home page. (v0.3.176, v0.3.178, v0.3.198)
- The Help search bar shows matching sections as you type. Help has new pages on reviewing time, finding and printing POs, child POs, committing expenses, profiles and rate sheets. More screens have a **Help** button. (v0.3.176, v0.3.187, v0.3.189, v0.3.190, v0.3.193, v0.3.194, v0.3.197)

### Time

- Approvers can select **Share with another manager** on **Pending My Approval**, **Approved By Me** and a time sheet's details. (v0.3.176)
- On **Pending My Approval**, **Approved By Me** and **Shared with Me**, a **Rejected** time sheet shows who rejected it, when and why. (v0.3.176)

### Purchase orders

- **Revise** replaces **Revise Total**. It can also change the description, division, category or job of your Active PO. You can't revise a PO that a PO group created. (v0.3.188, v0.3.189)
- Payables staff can't convert a One-Time PO to Cumulative if its expenses are more than its total. (v0.3.184)
- On a PO in another currency, Turbo converts the fixed overspend amount from Canadian dollars to the PO's currency. (v0.3.176)

### Expenses

- The expense **Tracking** week page and the expense form show the currency of each amount. (v0.3.176)
- All payables staff can open an expense from **Settlement** with **View**. (v0.3.176)
- Turbo no longer counts an edited expense twice against the total of a Cumulative PO. (v0.3.176)

### Project requests

- You can delete your own project request while it is Draft, Recalled or Rejected. Select **Delete request**. (v0.3.172)
- On **Approvals**, approvers see the requests that they approved until procurement creates the job. (v0.3.175)

### Rate sheets

- A project can now have a rate sheet for each period. Turbo prices each time entry by the rate sheet in effect on its date. Procurement staff with revision access can select **New period** in the job's **Rate sheets** section. (v0.3.197)
- Admins can select **Move projects** to move active projects on older revisions to the latest revision. Earlier time keeps its price. (v0.3.199)
- Turbo won't save a rate sheet with the same rates as another active sheet. While you edit, it lists active sheets with almost the same rates. (v0.3.191, v0.3.192)
- **Duplicates** on **Rate Sheets** groups sheets with the same rates. Admins, and staff with both absorb access and revision access, can absorb them into one sheet. (v0.3.194)
- Admins can **Rename** a rate sheet. All of its revisions get the new name. (v0.3.191)

- Every new project and subjob now starts as a project request. An approver checks it, then procurement creates the job. (v0.3.125)
- **Help** now has guides to Turbo, and many screens link to the matching guide. (v0.3.159, v0.3.162, v0.3.163, v0.3.164, v0.3.168)
- You can change the total or currency of an Active PO that you created, if it has no expenses or child POs. Select **Revise Total**. The PO needs approval again and keeps its number. (v0.3.161, v0.3.166)
- PO details now show actions as labelled buttons, such as **Approve** and **Reject**, instead of icons. (v0.3.166)
- Staff with PO group access can use **PO Groups** to create one PO for each of many staff from a template and a CSV file. Each PO still needs approval. (v0.3.154)
- Procurement now confirms a checklist before **Create Job**, and can **Reject** a project request with a reason. (v0.3.160, v0.3.165)
- The project request form now has the same search boxes and labels as the job form. (v0.3.167)
- **Value Approvals** and the **Project Requests** lists now look like the PO and expense approval lists. (v0.3.155)
