# Absorb suggestions

Turbo finds clients and vendors that are probably duplicates and shows them in buckets, best first. Only staff with absorb access can use this page.

## Find duplicates

1. On **Clients** or **Vendors**, select **Absorb suggestions** beside the search bar.
2. Select the **Clients** or **Vendors** tab.
3. Select **Strict**, **Normal** or **Loose** to show closer or looser matches.

The number on each tab is the buckets that are left.

## Absorb a bucket

1. Select the record to keep in the **Keep** column. Turbo suggests the record with the most uses.
2. Tick each duplicate to absorb. Select anywhere on its row.
3. Select **Absorb**.

You can't tick a record that is in an absorb proposal. Records that you don't tick stay in the bucket.

## Commit or undo

After **Absorb**, Turbo shows what it absorbed.

- Select **Commit** to finish. Turbo goes to the next bucket.
- Select **Undo** to put the records back. The bucket keeps your ticks.

If you close the window, a **Pending absorb** notice shows. Select **Review** to open it again. You can't absorb again on that tab until you commit or undo.

## Not duplicates

Select **Not duplicates** if the records in a bucket are different. Turbo hides the bucket for everyone. It shows again only when a new record joins it.
