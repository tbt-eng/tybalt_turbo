# Clients

A client has contacts and invoicing profiles. Jobs and project requests use them.

## Find where a contact or profile is used

1. Select **Clients** under **Business**. Select the client.
2. Find the contact or the invoicing profile.
3. Select its count of jobs and requests.

Turbo lists each job and project request. For a contact, a label shows its role: **Project contact**, **Invoice recipient** or both.

The list leaves out project requests that you cannot open.

## Use an email that another contact has

Each email address can belong to one contact only. If another contact has the email, Turbo does not save. The message names the client of that contact.

## Delete an unused invoicing profile

Procurement can delete an invoicing profile that no job or project request uses.

1. Select the client. Select the invoicing profile.
2. Select **More actions**.
3. Select **Delete invoicing profile**. Confirm the delete.

To retire a profile that is in use, replace it.

## Replace an invoicing profile

Procurement can replace an invoicing profile. Turbo moves its jobs and project requests to another profile of the client, then deletes it. You cannot undo this.

1. Open the profile to retire.
2. Select **More actions**.
3. Select **Replace with…**.
4. Select the other profile in **Replace with**.
5. Select **Replace profile**.

A moved project request keeps its approval.

## Set the profile of a project request

Procurement can set, change or clear the invoicing profile of a request in the **Job Create Queue**. The approval stays valid.

1. Open the request.
2. On the **Invoicing** card, select **Set profile** or **Change profile**.
3. Select the profile.
4. Select **Save profile**.

No profile fits? Select **Create an invoicing profile**. It opens in a new tab. Then select **Check again**.

## Find projects without a profile

The invoicing profile is optional. Procurement can list the Active projects that have none.

1. In the menu, select **Job Reports**.
2. Select **No Invoicing Profile**.
3. Open a project. Select **Edit Job**.
4. Select an invoicing profile. Save the job.
